# Iniciativas

Esta categoria guarda escopo, status, dependências e rollout de mudanças temporárias. Contratos
estáveis ficam em arquitetura; decisões, em ADRs; passos de operação, nos runbooks.

A padronização de documentação e harness tem artefatos em
[`.specs/features/docs-e-harness/`](../../.specs/features/docs-e-harness/spec.md).
Não há iniciativa de mudança funcional ativa registrada.
