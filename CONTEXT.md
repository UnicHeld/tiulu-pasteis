# Tiulu Pastéis

Vocabulário do domínio usado nas conversas, documentação e interface.

| Termo                    | Significado                                                                   |
| ------------------------ | ----------------------------------------------------------------------------- |
| Produto                  | Item do cardápio com preço em centavos, disponibilidade e estoque             |
| Preço promocional        | Valor definido pelo gestor, positivo e menor que o preço normal               |
| Sacola                   | Seleção temporária no navegador; não reserva estoque                          |
| Pedido                   | Compra registrada no servidor, com itens e preços preservados                 |
| Retirada                 | Entrega presencial no balcão, imediata no expediente ou agendada              |
| Agendamento              | Retirada entre 15 minutos e 7 dias, dentro do horário de funcionamento        |
| Código de acompanhamento | Credencial secreta de leitura de um pedido anônimo                            |
| Gestor                   | Sessão autorizada no servidor a operar pedidos e estoque                      |
| Pagamento confirmado     | Recebimento presencial conferido e marcado pelo gestor                        |
| Fidelidade               | Contagem de pedidos autenticados, pagos e entregues; sem resgate implementado |

Não confundir pedido recebido com pagamento aprovado, nem pedido pronto com pedido entregue.
Regras e limites vigentes: [conceitos fundamentais](docs/arquitetura/conceitos-fundamentais.md).
